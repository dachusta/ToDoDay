# ToDoDay — документация и стартовый скаффолд

ToDoDay — PWA-приложение для микроменеджмента дня: дела с приоритетом и цветом, шаблоны дня, размещение дел в сетке с шагом 15 минут, завершение дня и статистика.

Документация состоит из четырёх частей с собственной нумерацией разделов; ссылка всегда идёт с префиксом части («ТЗ §2.7», «вайрфреймы §8», «контракты §3.4», «скаффолд §6»).

## Правила

- **Источник истины для поведения** — требования и контракты. Если код в [`scaffold/`](scaffold) расходится с контрактом, правится код.
- Скаффолд реализует подмножество контрактов: таблица гэпов и критерии их закрытия — в [Скаффолд-ToDoDay.md](Скаффолд-ToDoDay.md) §6, план работ — в [§11](Скаффолд-ToDoDay.md). Это объём работ, а не «сломанный» код.
- `scaffold/` — оверлей, а не самостоятельное приложение: часть файлов создаёт мастер Quasar, часть ещё не написана. Порядок сборки — [Скаффолд-ToDoDay.md](Скаффолд-ToDoDay.md) §0 и [§12](Скаффолд-ToDoDay.md).
- Любая правка документа фиксируется в [журнале](Журнал-правок-ToDoDay.md) отдельным приложением с номером ревизии.
